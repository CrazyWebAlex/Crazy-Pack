# Crazy-Pack 🧰

**Reusable hand-coded HTML, CSS and JavaScript templates and frontend components by CrazyWebAlex.**

Crazy-Pack is a collection of reusable frontend templates and components built without CMS platforms or website builders.

The focus is on clean structure, responsive layouts and straightforward HTML, CSS and JavaScript.

---

## What you'll find here

- Hand-coded HTML templates
- Reusable CSS components
- JavaScript frontend elements
- Responsive layouts
- Mobile-first structures
- Landing page components
- Navigation and layout patterns
- Lightweight frontend solutions

---

No WordPress.  
No Wix.
